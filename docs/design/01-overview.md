# 1. プロジェクト概要

## 1-1. プロジェクトの目的

子どもおよび大人が音声でAIキャラクターと対話することを通じて、以下の能力を育成する。

- 好奇心・探究心
- 論理的思考力
- 仮説形成能力
- 想像力・創造力
- 多角的思考力
- 言語化・表現力
- 実務スキルの学習（大人向け。Pythonとそのライブラリ活用など）

AIは正解を提示することを主目的とせず、問いかけやヒントにより利用者自身の思考を促す。

本アプリは子ども向けとして始まったが、大人も対象へ拡大する。
大人に対しては、上記の思考力育成に加えて、Pythonとそのライブラリ活用を学べるユースケースを提供する。

## 1-2. 基本コンセプト

**「毎日ちょっとした冒険をしながら、自分で考えることが好きになる」**

| 項目 | 方針 |
|---|---|
| 利用者 | 家庭内の複数の子どもおよび大人 |
| 利用形態 | 音声対話 |
| AI | ローカルLLM |
| 音声認識 | ローカルSTT |
| 音声合成 | VOICEVOX |
| キャラクター | 複数の個性的な話し相手 |
| ゲーム性 | ミッション・スタンプ・図鑑・称号 |
| 記憶 | 子ども別の長期記憶 |
| 管理 | 保護者向け管理画面 |
| 動作環境 | 自宅サーバーを中心とするローカル環境 |

## 1-3. 設計原則

以下をすべての機能に共通する原則とする。

**原則1：思考過程を重視する**

正解したかどうかだけでなく、考えたこと、説明したこと、新しい視点を発見したことを評価する。

**原則2：AIは答えを急がない**

質問に対して即座に答えるのではなく、子どもが考える余地を残す。

**原則3：遊びの時間を尊重する**

利用時間の長さを評価しない。短時間で達成感を得られるようにする。

**原則4：利用者の個性を尊重する**

年齢による一律の難易度設定を避け、利用者ごとの興味・理解度・対話傾向に合わせる。
登録時に収集する生年月日（から算出した年齢）は、会話レベルの参考材料としてのみ扱う。
参考材料とは語彙や説明の具体度の目安を指し、難易度を自動的に決定する唯一の要素にはしない。

**原則5：AIへの依存を促さない**

AIは現実の体験、親子の会話、友達との交流を補完する存在とする。

**原則6：プライバシーを守る**

音声・会話・プロフィール情報を原則として家庭内環境で管理する。

# 2. システム全体の機能仕様

機能を7つのサブシステムに分割する。

| ID | サブシステム | 主な機能 | MVP |
|---|---|---|---|
| F01 | ユーザー管理 | 子ども・大人別アカウント・プロフィール（生年月日） | 必須 |
| F02 | 音声対話 | STT・LLM・TTS | 必須 |
| F03 | キャラクター | 性格・音声・対話スタイル | 必須 |
| F04 | ミッション | 問題生成・出題・進行管理 | 必須 |
| F05 | ゲーミフィケーション | スタンプ・称号・図鑑 | 一部 |
| F06 | Memory | 興味・過去の対話・思考記録 | 一部 |
| F07 | 保護者管理 | 利用状況・履歴・時間制限 | 必須 |

各サブシステムの具体的な仕様は [02-features.md](02-features.md) を参照のこと。

## 優先順位

本プロジェクトでは、以下の優先順位を採用する。

1. 教育的に意味のある対話ができること。
2. 子どもが自発的に使いたくなること。
3. 毎日短時間で達成感を得られること。
4. 子どもごとの興味や成長を蓄積できること。
5. ローカル環境で安定して動作すること。
