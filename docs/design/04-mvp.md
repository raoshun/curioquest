# 13. MVPの実装範囲

構想は発展性が高い反面、最初から全部実装しようとすると開発期間が長くなる。
そこで、MVPは以下の範囲に限定する。

## 13-1. MVPで実装する機能

| 機能 | 実装内容 | 優先度 |
|---|---|---|
| 子ども管理 | 複数アカウント切り替え | P0 |
| 音声対話 | STT・LLM・TTS連携 | P0 |
| キャラクター | 3種類 | P0 |
| ミッション | 3種類のカテゴリ | P0 |
| 対話制御 | 状態管理・終了判定 | P0 |
| スタンプ | 6種類 | P0 |
| 利用時間制限 | 1日あたりの上限 | P0 |
| 会話履歴 | 子ども別保存 | P0 |
| Memory | 興味・発見の記録 | P1 |
| 保護者画面 | 利用履歴・発見記録 | P1 |
| 図鑑 | 獲得スタンプ一覧 | P1 |

P0は初回リリースに必須、P1はMVPの初期改善で追加する機能である。

## 13-2. MVPでは実装しない機能

以下は将来の拡張候補とする。

- キャラクターの高度なアニメーション
- キャラクター同士の掛け合い
- キャラクターとの複雑な親密度システム
- 高度な思考力分析
- 自動生成による完全なミッション配信
- 複数モデルによる高度なエージェント構成
- 画像認識・カメラ連携
- 外出先からのリモートアクセス
- 家庭間ランキング・SNS機能
- 大人ユーザー向けスキル習得ミッション（Pythonとそのライブラリ活用）

特に、画像認識は将来的に面白い機能だが、まずは音声対話だけで十分な教育体験を作れることを確認したい。

## 13-3. 対象拡大の決定（2026-11）

本仕様では、対象を大人へ拡大する以下の方針決定を反映した。

| 拡張 | 仕様上の位置づけ | 詳細 |
|---|---|---|
| 大人ユーザーのアカウント | F01（3-1・3-2） | 子どもと同じプロフィール構造で利用可能にする |
| 登録時の生年月日必須入力 | F01（3-3）・F02（4-4） | 算出した年齢を会話レベルの参考材料として対話エンジンへ渡す |
| スキル習得ミッション | F04（6-5） | Pythonとそのライブラリ活用を最初のユースケースとする |

これらは初回リリース後の 06-roadmap Phase 6 で実装することを前提とし、上表のMVP範囲には含めない。

# 14. MVPの具体的なユーザー体験

実際の画面遷移を定義する。実際には子ども向けUIの文字量を減らし、音声とイラストを中心にすることを優先する。
