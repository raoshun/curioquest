# 20. 最初に実装するもの

最初の開発タスクは次のように定義する。

**「音声対話による思考力育成エンジン」の開発**

画面やスタンプを作る前に、以下の一連の動作を完成させる。

```text
1. 子どもがマイクに話しかける

2. faster-whisperで音声認識

3. LLMが発話の意図を理解

4. 対話制御エンジンが現在の状態を判断

5. LLMが子どもの思考を促す質問を生成

6. VOICEVOXで音声再生

7. 子どもの回答を受け取る

8. 対話内容から思考評価情報を生成

9. ミッション完了を判定

10. 対話結果を保存
```

この部分を独立したサービスとして成立させれば、その上にキャラクター、ゲーム、Memory、保護者機能を積み重ねられる。

## タスクの完了条件

- 上記1〜10が一気通貫で動作する（Phase 0 の技術検証と統合してよい）。
- 対話の進行（状態遷移）・終了判定がLLMに依存せず、アプリ側の対話制御エンジンで管理されている。
- 音声データはSTT処理後に破棄され、テキストのみが保存される。
- 対話が長引きすぎないよう、ミッション終了条件（[02-features.md](02-features.md) 6-4）が機能している。
