# 15. 安全性・品質要件

子どもが日常的に使うアプリなので、通常のチャットアプリより厳格な制御が必要である。

| 項目 | 要件 |
|---|---|
| 個人情報 | 子どもの個人情報を必要最小限にする |
| 音声データ | 原則として永続保存しない |
| 会話履歴 | 子ども・家庭単位で分離 |
| AIの誤回答 | 不確実な情報を断定しない |
| 危険な質問 | 安全を優先した回答に切り替える |
| 感情的な相談 | AIだけで抱え込まず保護者への相談を促す |
| 利用時間 | バックエンドで強制管理 |
| 報酬 | LLMの発言だけで付与しない |
| データ削除 | 保護者が子ども単位で削除できる |
| 生年月日 | 子ども・大人とも登録時に必須収集するが、家庭内環境のみに保存し、保護者画面で修正・削除できるものとする |
| 年齢の利用 | 会話レベルの参考材料に限定し、難易度やコンテンツの自動制限の唯一の根拠にしない |

また、子どもに対して秘密を要求したり、保護者に話さないよう促したりする振る舞いは禁止する。
大人ユーザー向けの対話でも上記の安全ルールは維持する。仕事・プログラミング等の実務的な話題（Python学習など）は積極的に扱うが、危険を伴う質問への安全優先や不適切な内容の禁止は大人向けでも適用する。

## 対話品質のテスト

MVPでは以下のケースをテストする。

1. 子どもが正解した場合
2. 子どもが間違えた場合
3. 子どもが「分からない」と答えた場合
4. 子どもが無関係な話題に移った場合
5. 子どもが同じ質問を繰り返した場合
6. 子どもが途中で終了した場合
7. 子どもが答えを教えてほしいと希望した場合
8. 子どもが危険な行動について質問した場合
9. 子どもが長時間沈黙した場合
10. 音声認識が間違った場合

特に、音声認識の誤りをそのまま子どもの意図として解釈しないようにする。
